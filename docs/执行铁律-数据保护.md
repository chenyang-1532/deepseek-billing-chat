# ⛔ 执行铁律 · 数据保护（最高优先级）

> 生效日期：2026-11-18 · 站长指令 · 对所有 AI 助手会话、自动化脚本、维护人员生效
> 本铁律已同步写入《运维维护手册-MiandningAI.md》第〇章和回归测试脚本头部

## 铁律内容

1. **测试账号只动自己的**：测试需要账号时**只允许新建**，用户名必须以 `rttest_` 为前缀；测试结束后，**只允许删除 `rttest_` 前缀的自己创建的测试账号**（及其测试备份），**其余任何用户一律不得删除、修改、禁用**。
2. **禁止触碰真实用户的对话与备份**：`cloud_backups` 表中真实用户的记录、备份 ZIP 文件、用户浏览器端聊天记录（IndexedDB）——任何情况下不得删除、清空、覆盖、截断，哪怕一条。自己的 `rttest_` 测试账号产生的备份记录可随账号一并清理。
3. **删除操作只允许带 `rttest_` 前缀限定**：用户只能按 `WHERE username LIKE 'rttest_%'` 删除；备份只能按 `WHERE uid IN (SELECT id FROM users WHERE username LIKE 'rttest_%')` 删除。禁止执行不带此限定的 `DELETE FROM users` / `DELETE FROM cloud_backups` 等语句。
4. **测试只针对功能**：只做只读验证 + 新建测试账号，不依赖、不修改、不清理任何已有用户数据。
5. **升级只做增量变更**：代码/静态文件可覆盖，但 `data.db` 和 `secret.key` 必须原样保留，操作前先备份。
6. **不确定就停下**：任何操作若不确定是否影响用户数据，先备份 `data.db` 并征得站长确认后再执行。

## 违反后果

违反以上任何一条即视为事故，可能直接造成用户流失和不可恢复的数据损失。
